提交之后

投稿会成为公开的 GitHub Issue，文字、附件和后续讨论都能被访客看到。请只放愿意公开的内容。

编辑会在这条 Issue 里回复。你可以补充材料、确认官网展示范围和原文件下载条件，也可以申请更正署名或撤下展示。
